# AWS-IoT-Core-Raspberry-Pi-Environmental-Monitor

Project Goal

Let's first understand what we're actually building.

Imagine your Raspberry Pi as a small computer sitting in your house.

Every 30 seconds it will:

Check its CPU usage
Check memory usage
Check disk usage
Send that information to AWS

AWS will then:

Receive the information
Store it
Display it
Generate alerts if something goes wrong

This is almost identical to how real IoT devices work in production.

Examples:

Smart thermostats
Parking kiosks
Smart vending machines
Industrial sensors
Security cameras
Parcel lockers
